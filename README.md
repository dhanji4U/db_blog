# Personal Blog

A responsive personal blog built with **Next.js**, **TailwindCSS**, and **TypeScript**. This project focuses on the UI of a personal blog with a mobile-first responsive design.


## Features

- Responsive UI design that adapts to different screen sizes (mobile, tablet, desktop).
- Clean and minimalistic design for easy reading.
- Built using **Next.js** for server-side rendering and routing.
- Styled with **TailwindCSS** for fast and custom UI styling.
- TypeScript for type safety and better development experience.

## Tech Stack

- **Next.js**: Framework for React, provides server-side rendering, static site generation, and routing.
- **TailwindCSS**: Utility-first CSS framework for quickly building custom designs.
- **TypeScript**: Superset of JavaScript providing static typing, making the codebase more reliable and maintainable.
